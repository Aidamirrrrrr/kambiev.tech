# kambiev.tech

Сайт-портфолио **Айдамира Камбиева**, fullstack-разработчика.

**Стек:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion, Lenis

**Демо:** [kambiev.tech](https://kambiev.tech)

---

## Что внутри

- App Router, серверный рендеринг, вывод в `standalone` для Docker
- Интернационализация RU / EN: словари типизированы друг по другу, язык хранится в куке
- Витрина из семи проектов с настоящими снимками продуктов в рамках устройств
- Техническая часть каждого проекта раскрывается по клику: верхний слой читается без бэкграунда в разработке
- Плавная прокрутка (Lenis) с перехватом кликов по якорям и поправкой на фиксированную шапку
- Форма обратной связи: заявка уходит в Telegram через Bot API
- SEO: связанный граф JSON-LD, Open Graph, `sitemap.xml`, `robots.txt` с явным разрешением ИИ-краулеров, `llms.txt`
- Политика конфиденциальности отдельной страницей, рендерится на сервере

## Доступность и производительность

Замерено Lighthouse по прод-сборке:

| | Десктоп | Мобильный |
|---|---|---|
| Производительность | 100 | 92 |
| Доступность | 100 | 100 |
| Лучшие практики | 100 | 100 |
| SEO | 100 | 100 |

Все текстовые узлы проходят WCAG AA по контрасту. Настройка «меньше движения»
отключает плавную прокрутку и анимации и принудительно раскрывает содержимое,
которое Framer Motion держит скрытым в inline-стилях.

## Структура

```
src/
├── app/
│   ├── api/contact/         заявка из формы в Telegram
│   ├── api/inbound-email/   вебхук Resend с проверкой подписи
│   ├── privacy/             политика конфиденциальности
│   ├── llms.txt/            выжимка для языковых моделей
│   ├── layout.tsx           метаданные и структурированные данные
│   ├── manifest.ts          веб-манифест
│   ├── robots.ts            robots.txt
│   └── sitemap.ts           sitemap.xml
├── components/
│   ├── sections/            секции страницы
│   ├── form/                поля формы с плавающими подписями
│   ├── ui/                  магнитная ссылка
│   ├── device-frame         рамки браузера и телефона для снимков
│   ├── disclosure           раскрытие деталей по клику
│   ├── custom-cursor        след за системным курсором
│   ├── locale-transition    анимация смены языка
│   └── smooth-scroll        Lenis и обработка якорей
└── lib/
    ├── site.ts              адреса и контакты, единственный источник
    ├── social.ts            внешние профили
    ├── projects.ts          данные витрины
    ├── stack.ts             технологический стек
    ├── telegram.ts          помощники Bot API
    ├── i18n.tsx             провайдер локали
    └── dictionaries/        словари RU и EN
```

## Запуск

```bash
pnpm install
pnpm dev
```

Проверки:

```bash
pnpm lint        # biome
pnpm typecheck   # tsc --noEmit
pnpm build
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните. Без них сайт собирается
и работает, но форма и пересылка почты молча ничего не делают.

| Переменная | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | заявки из формы |
| `MAIL_BOT_TOKEN`, `MAIL_BOT_CHAT_ID` | пересылка входящей почты |
| `RESEND_API_KEY`, `RESEND_WEBHOOK_SECRET` | чтение письма и проверка подписи вебхука |

## Деплой
